# Portal documental Villa Los Robles

## Publicación en GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Suba todo el contenido de esta carpeta.
3. Abra **Settings**.
4. Ingrese a **Pages**.
5. En **Build and deployment**, elija **Deploy from a branch**.
6. Seleccione la rama `main` y la carpeta `/ (root)`.
7. Presione **Save**.

## Edición visual

En F01, presione **Editar textos**, haga sus cambios y luego use **Descargar HTML modificado**.
